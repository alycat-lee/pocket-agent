## 一、问题 2 诊断："你是谁"为什么返回"未找到相关资料"

**完整故障链**（每条都已核实到代码）：

1. `try_rule("你是谁")`：无工具词、无 writer 词 → 命中"短句闲聊" → 模式 qa（这步没错）。
2. `default_card()` 调 `infer_needs_knowledge("你是谁")`：`_KNOWLEDGE_HINTS` 里**有"谁是"这个子串**（task/__init__.py:30-48）→ `needs_knowledge=True`。
3. `_run_qa()`（session/__init__.py:597）：`needs_knowledge` → 检索知识库 → 知识库为空 → **直接短路返回 EMPTY_RESULT"未找到相关资料"，模型根本没被提问**。
4. 即使放行模型回答，`Verifier._citation_problems`（verifier/__init__.py:118）在 `needs_knowledge=True` 且证据为空时，只要回答不含"未找到资料"就判"请仅基于检索资料回答"→ 验收驳回。**双保险全都是错的。**

**对标 DSH / 豆包的机制差异**：

| 场景 | DSH/豆包的做法 | 我们当前的做法（错误） |
|------|--------------|---------------------|
| 你是谁/自我介绍/闲聊 | 纯模型回答（system prompt 人设），绝不碰知识库 | 被"谁是"子串误判为知识依赖 → 硬拒 |
| 事实型问题（最新/今年/谁写的） | 有检索则注入资料；**检索为空回退模型自身知识回答** | 检索为空 = 终态回答"未找到相关资料" |
| 显式限定"根据文档/知识库回答" | 检索为空才拒答 | （唯一应该拒答的场景，目前和无差别混在一起） |
| RAG 忠实性红线（禁止编造） | 只在**注入了资料**时生效 | 对所有 QA 生效，包括根本没检索的 |

结论：我们把"RAG 忠实性红线"错误地当成了所有问答的默认门禁。正确机制是**知识依赖三档分级**：`none`（不检索）/ `augment`（检索增强，空则回退纯模型）/ `strict`（显式限定资料，空才拒答）。
