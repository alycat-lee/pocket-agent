## 二、任务 A：DuckDuckGo 免配置后端（src/knowledge/web.py）

在现有 searxng → serper 链后加第三级默认后端，无需任何配置：

```python
def web_search(query, *, searxng_url="", serper_key="", timeout=DEFAULT_TIMEOUT):
    q = (query or "").strip()
    if not q:
        return EMPTY_RESULT
    if searxng_url:
        return _searxng(q, searxng_url, timeout)
    if serper_key:
        return _serper(q, serper_key, timeout)
    return _duckduckgo(q, timeout)
```

`_duckduckgo` 要求：

1. GET `https://html.duckduckgo.com/html/?q=...`，`User-Agent: Mozilla/5.0`，沿用现有 httpx 客户端与 `_is_blocked_url` 防护；
2. 用正则/`html.parser`（stdlib）解析 `result__a`（标题+链接）与 `result__snippet`（摘要），取前 5 条，格式与现有后端一致：`[来源：网页搜索] 标题 — 摘要`；
3. **任何网络错误、超时、HTTP 非 200、解析为空 → 返回 EMPTY_RESULT，不抛异常**。DDG 限流时表现为静默降级，后端可观测性走现有 llm.call / step 事件即可；
4. 不加磁盘缓存，不加重试——失败就诚实，别制造复杂性。

单测：用 fixture HTML（tests/fixtures/ddg_sample.html，从真实响应截取 3 条结果）测解析；模拟超时/403/空页 → EMPTY_RESULT。

## 三、任务 B：QA 的确定性联网回退（src/session/__init__.py）

当前 augment 模式检索为空时，无历史的题直接把"未找到相关资料"塞进 prompt，模型只能复读。改为：

在 `_run_qa` 中，`card.knowledge_mode == "augment"` 且本地检索为空 **且 `has_history` 为 False** 时：

1. 代码层直接调一次 `web_search(query)`（走 knowledge 插件已注册的工具函数，不经 LLM choose，不经账本）；
2. 有结果 → 作为 evidence 注入 FINAL_ANSWER_QA，正常作答并走来源尾注逻辑（"只答日期"类由 `wants_bare_answer` 抑制尾注，已有）；
3. 无结果 → 维持现状返回"未找到相关资料"（**这是 d7 两道反幻觉题的保命行为，不能破**）。

**防误触发红线（必须实现）**：

- `has_history=True` 时**不**联网——d9-pronoun"它是什么颜色的？"是 augment 题，联网会搜出垃圾。有历史一律历史优先；
- `knowledge_mode == "strict"` 不联网（strict 语义就是"只用私有库"）；
- 每轮最多一次 web 调用，不做查询改写、不做多跳。

**反幻觉护栏**：对 web 结果做实体过滤——从 query 提取《》内词组和 ≥4 字的连续中文/拉丁词，要求至少一个出现在合并后的标题+摘要里，否则按 EMPTY_RESULT 处理。防止"紫晶河水母币"这种虚构词搜出无关结果后模型瞎编。

单测（tests/test_session.py 或 test_knowledge.py）：

- augment + 空检索 + 无历史 + web 有结果 → evidence 含"[来源：网页搜索]"；
- augment + 空检索 + **有历史** → 不调 web（monkeypatch web_search 断言未调用）；
- web 结果不含查询实体 → 按空处理；
- strict 模式不调 web。

## 四、任务 C：dup_call_rate 口径修复（并入，原 Phase 51）

按 38 号文档方案重写 `benchmark/runners/pocket.py` 的 `_dup_call_rate`：只对非缓存、非伪步（`(format_error)`/`(domain_gate)`）的步取指纹，`rate = (len(real_fps) - len(set(real_fps))) / len(real_fps)`，空列表返回 0.0。real_calls 参数保留但不参与计算。四条回归单测照 38 号文档执行。
